# @damatjs/orm-core 1.0.4

> Query logs redact SQL parameter values by default.

## Added

- `QueryLoggerOptions.logParameters` for explicit parameter logging.

## Changed / improved

Successful, slow, and failed query logs include parameters only when `logParameters: true` is configured.

## Breaking

- Parameter values no longer appear in default query logs.

## Action required

Set `logParameters: true` only in controlled environments that permit potentially sensitive values.
