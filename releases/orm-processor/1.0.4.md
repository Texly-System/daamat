# @damatjs/orm-processor 1.0.4

> Migration generation now preserves schemas and table integrity constraints across snapshots and diffs.

## Added

- Primary key, unique, check, and exclusion constraint diff and SQL generation.
- Partial unique indexes and exclusion predicates.
- Dependency ordering for initial table creation.

## Changed / improved

Column, index, foreign key, constraint, and table SQL is schema-qualified. Enum value removal and table schema moves fail closed.

## Breaking

- Previously advisory unsupported destructive changes now throw generation errors.

## Action required

Replace rejected destructive changes with explicit reviewed migrations.
