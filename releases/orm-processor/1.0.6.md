# @damatjs/orm-processor 1.0.6

> Native pgvector schema processing and migration DDL.

## Added

- Additive `create_extension` diffs and snapshot normalization for required
  PostgreSQL extensions, including inferred `vector` for `vector`/`halfvec`
  columns. Extension creation is emitted before enums and tables; extension
  drops are never generated.
- Exact `VECTOR(n)` and `HALFVEC(n)` column SQL using `dimensions` metadata.
- HNSW/IVFFlat index DDL with named columns or raw expressions, vector operator
  classes, deterministic storage parameters, predicates, and concurrent create
  and drop handling.

## Changed

- Native vector type or dimension changes now produce a clear warning and a
  manual-review SQL comment instead of an automatic cast. Safe nullability and
  default changes on the same column remain executable.
- Reverse diffs preserve vector dimensions and concurrent index-drop metadata.

## Compatibility note

- This release is paired with the ORM model contract change: `columns.vector(n)`
  now means native PostgreSQL `VECTOR(n)` rather than a `REAL[]` compatibility
  column. Existing snapshots require an application-reviewed data migration.
