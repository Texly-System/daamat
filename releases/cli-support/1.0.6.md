# @damatjs/cli-support 1.0.6

> Scaffold commands now share safe, optional Git initialization.

## Added

- `initializeGit` probes the system Git executable, creates the `main` branch,
  stages generated files, and creates one initial commit.
- Git failures are actionable warnings that preserve the scaffold; callers can
  pass `--no-git` to skip probing and all Git commands.

## Fixed

- Installer option adaptation accepts one scalar target or an ordered repeated
  target array and maps duplicate capabilities deterministically to the last
  supplied path.
