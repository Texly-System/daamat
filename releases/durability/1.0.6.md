# @damatjs/durability 1.0.6

> Framework durability relations now live in the dedicated `damat` schema.

## Added

- A forward system migration relocates shared idempotency, worker, control,
  maintenance, acceleration, and retention relations from `public` to `damat`.
- Shared helpers produce qualified Damat relation names and conflict-safe,
  idempotent relocation SQL for capability packages.
- Relocation preflight rejects schemas outside the migration role's control and
  schemas containing unrelated relations, with reconciliation guidance.

## Changed

- Runtime and readiness SQL is fully qualified and does not depend on
  `search_path`.

## Action required

Run system migrations before starting 1.0.6 processes. Separate runtime roles
need `USAGE ON SCHEMA damat` and privileges on the enabled infrastructure
tables. Existing table grants survive relocation.
