# @damatjs/durability 1.0.4

> Idempotency keys now bind to a canonical SHA-256 fingerprint of their intended operation.

## Added

- Canonical JSON serialization and SHA-256 intent fingerprint helpers.
- Public `IdempotencyConflictError` for reused keys with incompatible or unverifiable intent.
- Append-only system migration `005` for `intent_fingerprint`.

## Breaking

- Reusing a key whose stored fingerprint is missing or different now fails closed.

## Action required

Run `bun run db:migrate` before starting 1.0.4 processes.
