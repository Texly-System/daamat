# @damatjs/workflow-engine 1.0.4

> Workflow start logs no longer serialize execution input.

## Changed / improved

Workflow lifecycle logs retain workflow and execution identifiers while excluding input values, including objects with hostile or throwing serialization hooks.

## Breaking

- Workflow input is no longer available in default start log records.

## Action required

Use an explicitly reviewed observer with redaction if telemetry requires selected input fields.
