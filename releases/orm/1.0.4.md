# @damatjs/orm 1.0.4

> The ORM umbrella exposes lossless NUMERIC metadata and stronger migration integrity behavior.

## Changed / improved

The coordinated ORM packages now support opt-in numeric string representation, schema-qualified integrity constraints, fail-closed enum removal, checksummed migration tracking, and audited adoption.

## Breaking

- Unsupported destructive enum and table-schema changes now fail generation instead of producing advisory output.

## Action required

Review newly rejected destructive migrations. Exact numeric strings remain opt-in through `.representation("string")`.
