# @damatjs/orm-type 1.0.6

> Native pgvector schema contracts replace the legacy REAL[] vector metadata.

## Added

- `ColumnType` now distinguishes PostgreSQL `vector` and `halfvec` values.
- `ColumnSchema.dimensions` records native vector dimensionality; `length`
  remains for character lengths and numeric precision.
- `ModuleSchema.extensions` records required PostgreSQL extensions.
- `IndexType` includes `hnsw` and `ivfflat`; index columns support SQL
  expressions, pgvector operator classes, and storage parameters.

## Compatibility note

`columns.vector()` now describes native `VECTOR(n)` rather than `REAL[]`. The
dimension field moved from `length` to `dimensions`, and consumers must review
existing snapshots and data migrations before upgrading to 1.0.6.
