# @damatjs/orm-pg 1.0.6

- Added native pgvector runtime support for modeled `VECTOR`/`HALFVEC` values,
  including exact-client registration, safe serialization, and retry after
  extension creation.
- Added `PgRepository.findNearest` with l2, cosine, inner-product, and l1
  distances and the collision-safe `{ row, distance }` result shape.
- Nearest-distance validation accepts only its four own operator keys, and
  vector serialization ignores `set` values that SQL discards for
  `ON CONFLICT DO NOTHING`.
