# @damatjs/module 1.0.6

> Standalone durable module harnesses use the dedicated Damat schema.

## Changed

- Durable harness readiness probes resolve infrastructure relations through
  the qualified `damat` schema.
- Module-owned application tables and generated migrations remain in their
  configured application schema.

## Action required

Apply the complete system migration catalog before starting standalone durable
workers. The runtime database role needs `USAGE ON SCHEMA damat` plus the
required table and sequence privileges.
