# @damatjs/module 1.0.4

> Standalone module harnesses now mirror production durability setup and restore shared process state safely.

## Changed / improved

- Durable module capabilities receive a shared durability client.
- Pipeline definitions synchronize after module initialization.
- Teardown is idempotent and restores any prior durability client.
- Standalone HTTP shutdown is bounded while service cleanup still runs.

- None.
