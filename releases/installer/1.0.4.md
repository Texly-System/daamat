# @damatjs/installer 1.0.4

> Install plans now retain deterministic capability mapping metadata.

## Added

- `InstallerPlan.capabilityMappings` with capability, provider source, destination, destination source, and operation count.

## Changed / improved

Profile-derived recipes carry resolved capability provenance into plan creation and reporting.

## Breaking

- None.

## Action required

None - drop-in upgrade. Consumers that serialize strict plan snapshots should accept the new field.
