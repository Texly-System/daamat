# @damatjs/installer 1.0.5

> Source planning prunes excluded content and preserves narrow capability routing.

## What changed

Source planning previously traversed excluded directories before applying
recipe mappings, and broad mappings could run before overlapping narrow
capabilities. Planning now prunes built-in, ignored, and provably unmapped
subtrees, evaluates symlinks only when selected, and orders manifest-derived
mappings by fixed-prefix specificity.

## Changed / improved

- `.git` and `node_modules` never enter source plans, even under a `**` mapping.
- Symlinks inside an artifact's installed dependencies no longer block source
  installation.
- Ignored and unmapped symlinks are skipped without being followed; selected
  symlinks remain rejected.
- Narrow capabilities such as routes and workflows win over `src/**`.

## Breaking

- None.
