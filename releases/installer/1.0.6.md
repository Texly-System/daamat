# @damatjs/installer 1.0.6

> Manifestless source modules ignore invalid heuristic provider candidates.

## Changed / improved

- Bare-source workflow, job, event, and pipeline resolution now selects the
  first direct file or directory with `index.ts`/`index.js`.
- An empty application-owned provider directory no longer shadows a valid
  module-local fallback; a valid application provider still wins.
- Explicit manifest paths remain authoritative and are not replaced by
  heuristic candidates.

## Breaking

- None.

## Action required

None — drop-in upgrade. Explicit provider paths still need a loadable file or
conventional directory index.
