# @damatjs/damat-cli 1.0.4

> The assembled CLI inherits strict nested option handling and audited migration adoption.

## What changed

Nested commands now reject unknown options, render resolved child help, preserve arguments after `--`, and expose the ORM migration adoption command through the assembled command tree.

## Breaking

- Unknown command options no longer pass through silently.

## Action required

Declare accepted options or use `--` before literal option-like arguments.
