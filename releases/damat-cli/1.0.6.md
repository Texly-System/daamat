# @damatjs/damat-cli 1.0.6

> Composed creation commands now expose consistent, optional Git setup.

## Added

- Composed help documents `--no-git` for both `create` and `module init`.
- Both commands initialize Git on `main` by default; Git failures warn without
  changing dependency or database setup behavior.

## Fixed

- Composed module and Kit command definitions retain repeatable installer
  `--target capability=path` options through planning and installation.
