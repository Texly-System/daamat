# @damatjs/orm-model 1.0.6

> Model builders emit native pgvector columns and complete ANN index metadata.

## Added

- `columns.vector(dimensions)` emits `VECTOR(dimensions)` metadata.
- `columns.halfVector(dimensions)` emits `HALFVEC(dimensions)` metadata.
- Vector dimensions are positive integers stored in `ColumnSchema.dimensions`
  and infer as `number[]`; native vectors reject `.array()`.
- `toModuleSchema()` deduplicates required extensions and adds `vector` when a
  model uses either native vector type.
- Index builders support `hnsw`/`ivfflat`, named or expression columns,
  operator classes, `with(...)` storage parameters, predicates, and concurrent
  creation. Expression indexes require explicit names.
- Root utility exports `assertVectorValue`, `assertColumnVectorValue`, and
  `isVectorColumn` provide the shared finite-number and exact-dimension runtime
  contract consumed by generated service validation.

## Compatibility note

The old `columns.vector()` REAL[] compatibility helper is redefined as native
`VECTOR(n)`. Existing snapshots and stored REAL[] data require application-
reviewed migration work for 1.0.6.
