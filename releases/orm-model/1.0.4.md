# @damatjs/orm-model 1.0.4

> NUMERIC columns can opt into lossless string representation for generated application types.

## Added

- `NumericColumnBuilder.representation("number" | "string")`.

## Changed / improved

The selected representation is retained in schema metadata without affecting SQL migration diffs. Existing columns continue to generate numbers by default.

## Breaking

- None.

## Action required

Use `.representation("string")` only for NUMERIC values that must preserve exact decimal precision.
