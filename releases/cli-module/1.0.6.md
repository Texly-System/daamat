# @damatjs/cli-module 1.0.6

> Standalone module scaffolds now match backend Git setup.

## Added

- `damat module init` initializes a `main` Git repository, stages the complete
  scaffold, and creates an initial commit by default.
- `--no-git` skips Git probing and setup. Missing Git, probe errors, and any
  setup-step failure warn while preserving the usable module package.

## Fixed

- Module plan, add, and update commands preserve repeated `--target
  capability=path` overrides and pass every destination to the installer.
