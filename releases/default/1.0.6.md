# @damatjs/default 1.0.6

> The reference deployment provisions and validates the dedicated Damat schema.

## Changed

- PostgreSQL role bootstrap creates `damat`, grants runtime and backup schema
  access, and configures default privileges for future infrastructure objects.
- Database acceptance verifies schema usage, ownership, and runtime CRUD
  privileges separately from application tables in `public`.
- Worker health, recovery, and restore checks use qualified infrastructure
  relations.

## Action required

Run the updated role bootstrap and system migrations before starting 1.0.6.
Existing restricted runtime roles need `USAGE ON SCHEMA damat` and privileges
on the enabled Damat tables and sequences.
