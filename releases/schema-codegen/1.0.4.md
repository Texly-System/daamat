# @damatjs/schema-codegen 1.0.4

> Lossless NUMERIC metadata now generates exact string types and decimal validation.

## Changed / improved

Columns marked with `numericRepresentation: "string"` generate TypeScript `string` values and finite decimal-string Zod schemas, including array and nullable forms. Unmarked NUMERIC columns remain numbers.

## Breaking

- None.

## Action required

Regenerate types after opting a model column into `.representation("string")`.
