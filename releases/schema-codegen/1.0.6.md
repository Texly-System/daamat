# @damatjs/schema-codegen 1.0.6

> Generated schemas now understand native PostgreSQL pgvector columns.

## Added

- `vector` and `halfvec` columns generate TypeScript `number[]` values.
- Generated new, update, and query Zod schemas require finite numbers and the
  exact positive `dimensions` declared by the model.
- Missing or invalid vector dimensions fail generation with a clear error.
- Ordinary PostgreSQL `real[]` and `double precision[]` columns retain their
  existing array mapping.

## Upgrade notes

Regenerate schema artifacts after migrating models to native `VECTOR(n)` or
`HALFVEC(n)` columns. Existing compatibility-helper snapshots require the
application-reviewed data migration described in the [1.0.6 native pgvector
plan](../../plans/1.0.6.md).
