# @damatjs/events 1.0.4

> Durable event idempotency keys now verify the complete canonical publish intent.

## Changed / improved

- Durable outbox rows persist an intent fingerprint.
- A reused idempotency key conflicts when topic, payload, delivery, or other persisted intent differs.
- Append-only system migration `006` adds fingerprint storage.

## Breaking

- Legacy rows without a verifiable fingerprint cannot be replayed under the same key.

## Action required

Run `bun run db:migrate` before starting durable event publishers or workers.
