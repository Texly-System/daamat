# @damatjs/events 1.0.6

## Changed

- System migration `007` relocates durable event outbox, delivery, attempt,
  activity, and log relations into `damat` while preserving stored history.
- Publishing, routing, workers, inspection, retention, and control SQL now uses
  fully qualified infrastructure relations.

## Action required

Run system migrations before starting 1.0.6 event processes. Runtime roles need
`USAGE ON SCHEMA damat` and durable-event table privileges.
