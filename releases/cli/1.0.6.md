# @damatjs/cli 1.0.6

> Repeatable command options now preserve every supplied value.

## Added

- `CommandOption.repeatable` marks options that accept repeated values.
- Marked options keep one occurrence scalar and accumulate later occurrences in
  argument order across separate, inline, and mixed value syntax.
- Repeatable arrays are coerced element by element by the declared option type.

Unmarked options retain their existing last-value behavior.
