# @damatjs/cli 1.0.4

> Command dispatch now handles nested help, unknown options, and literal positional arguments consistently.

## What changed

Manual subcommand dispatch now resolves child help without invoking handlers, rejects undeclared options, and treats every argument after `--` as positional.

## Breaking

- Commands that previously ignored unknown options now return an error.

## Action required

Declare accepted options or place option-like positional values after `--`.
