# @damatjs/orm-cli 1.0.6

> System migration commands include the dedicated-schema relocation catalogs.

## Changed

- Migration status and execution include the new durability, jobs, events, and
  pipelines relocation migration identities in global order.
- Existing application and module migration behavior remains unchanged.

## Action required

Run `damat-orm migrate:up` before starting 1.0.6 API or worker processes. The
migration role must be able to create and alter objects in the `damat` schema.
