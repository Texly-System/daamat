# @damatjs/orm-cli 1.0.4

> Operators can explicitly adopt a committed non-transactional migration that failed only during tracking.

## Added

- `damat-orm migrate:adopt <module> <migration> --checksum <sha256> --actor <actor> --reason <reason>`.

## Changed / improved

The command verifies source checksum, non-transactional SQL, configured ownership, and existing tracker state before recording an audited adoption.

## Breaking

- None.

## Action required

Use adoption only after independently verifying that the migration SQL committed successfully.
