# @damatjs/framework 1.0.4

> HTTP validation is body-aware and shutdown bounds the HTTP phase without abandoning service cleanup.

## Changed / improved

- JSON is parsed only when a route declares `body` or `json` validation.
- Empty and malformed JSON receive distinct validation responses; DELETE and falsy JSON bodies are supported.
- Assembled apps default to a 30-second shutdown grace period, and later cleanup continues after HTTP timeout.

## Breaking

- Malformed declared JSON bodies now fail validation consistently instead of surfacing incidental parser behavior.

## Action required

None - drop-in upgrade. Configure `runtime.shutdownGraceMs` only when the default is unsuitable.
