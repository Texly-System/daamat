# @damatjs/jobs 1.0.6

## Changed

- System migration `005` relocates all job relations into `damat` without
  copying or recreating durable state.
- Enqueue, worker, schedule, inspection, control, retention, and reconciliation
  SQL now uses fully qualified infrastructure relations.

## Action required

Run system migrations before starting 1.0.6 job workers. Runtime roles need
`USAGE ON SCHEMA damat` and job-table privileges.
