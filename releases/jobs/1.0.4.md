# @damatjs/jobs 1.0.4

> Job deduplication keys now bind to canonical enqueue intent.

## Changed / improved

- Deduplication rows persist and compare an intent fingerprint before replaying a result.
- Scheduled occurrence reconciliation uses the same intent contract.
- Append-only system migration `004` adds fingerprint storage.

## Breaking

- Legacy deduplication rows without a fingerprint conflict rather than replaying unverifiable intent.

## Action required

Run `bun run db:migrate` before starting job clients or workers.
