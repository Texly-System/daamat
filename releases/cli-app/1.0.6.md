# @damatjs/cli-app 1.0.6

> Generated backends now choose their runtime environment from `NODE_ENV`.

## Fixed

- The scaffolded `damat.config.ts` sets `projectConfig.nodeEnv` to
  `production` only when `NODE_ENV` is exactly `production`.
- Missing or other `NODE_ENV` values continue to select `development`.
- `damat create` now uses the shared Git setup helper to initialize `main`,
  stage the scaffold, and create an initial commit by default.
- `--no-git` skips the Git probe and every Git command. Missing Git and setup
  failures warn without removing the completed scaffold.

## Action required

Existing generated backends should update their own `damat.config.ts` to the
environment-aware expression. Regeneration is unnecessary. The Git default
applies to future `damat create` scaffolds; existing projects are unchanged.
