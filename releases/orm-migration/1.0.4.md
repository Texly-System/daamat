# @damatjs/orm-migration 1.0.4

> Migration execution and tracking now share transactional sessions and retain source integrity metadata.

## Added

- SHA-256 source checksums in migration tracker rows.
- Audited adoption for committed, untracked non-transactional migrations.
- `CommittedMigrationUntrackedError` for the ambiguous committed state.

## Changed / improved

Transactional SQL and its tracking insert use one checked-out client before commit. Tracking failure rolls back the migration.

## Breaking

- A non-transactional tracking failure is reported as committed-but-untracked and requires explicit operator recovery.

## Action required

Do not rerun an untracked non-transactional migration blindly; verify it and use `migrate:adopt`.
